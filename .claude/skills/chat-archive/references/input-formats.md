# 输入格式参考（Chat Archive）

## 1. 支持的明文格式与示例

### 1.1 微信/QQ 通用 TXT（单行式）
```
2026-10-01 09:00:00 客户小王: 在吗？昨天买的裙子什么时候发货？
2026-10-01 09:02:00 李四: 您好，今天下午统一发出，稍后给您单号
```
规则：`时间 发送人: 内容`，时间支持 `YYYY-MM-DD HH:MM:SS` / `YYYY-MM-DD HH:MM` / `YYYY/MM/DD`；冒号为中文或英文冒号。

### 1.2 QQ 消息管理器导出 TXT（两行式）⚠️ 最容易漏的格式
```
2026-10-01 09:10:00 李四(87654321)
客户退款已处理完毕
```
规则：第一行 `时间 发送人(QQ号)`，第二行是消息内容。脚本已支持，无需人工改写。

### 1.3 群标题行（可选，用于群归属）
```
==== 电商运营1群 ====
```
或 `# 电商运营1群` / `【电商运营1群】`。之后的同格式消息归入该群（用于超时归属与跟进分组）。不写群标题则归入空群。

### 1.4 Markdown（.md）
与 TXT 单行式相同，额外支持 `**时间 发送人: 内容**` 等加粗包裹。

### 1.5 JSON — 企业微信存档格式（WeCom archive）
```json
{"MsgId":"1","MsgType":"text","FromUserName":"张三","ToUserName":"电商运营1群","CreateTime":1727744400,"Content":"您好，今天下午统一发出"}
```
### 1.6 JSON — WeChatMsg / MemoTrace 导出（个人微信）
```json
{"msg_id":"...","sender_name":"李四","group_name":"电商运营1群","sent_at":"2026-10-01 09:02:00","content":"您好，今天下午统一发出"}
```
字段别名：`StrContent`/`content`、`Sender`/`sender_userid`、`CreateTime`（秒/毫秒时间戳均可）、`ChatRoomName`/`group_id`。

### 1.7 CSV
表头含列名（大小写/别名均可）：时间(`sent_at`/`time`/`发送时间`)、发送人(`sender_userid`/`发送人`/`昵称`)、内容(`content`/`内容`)、群(`group_id`/`群`)。缺列时跳过该列。

## 2. 加密备份（微信官方备份，.db/.bak/.zip/.dat）

微信官方备份为**私有加密格式**，脚本无法直接读取明文。两种路径：
- **A（推荐）**：用户先用本机 wechat-cli 类工具（WeChatSCI 等）导出为明文 TXT/MD/JSON/CSV，再把明文文件交给本 Skill；
- **B**：直接传入加密备份 + `--tool-cmd`，脚本自动调用本机工具转换后再解析：
  ```bash
  python3 .../chat_archive.py all --input wx_backup.db \
    --staff "张三,李四" \
    --tool-cmd 'wechat-cli export --input {input} --output {dir}'
  ```
  `{input}` 为备份文件路径、`{dir}` 为输出目录，脚本自动替换。未配置工具时脚本提示跳过，不报错。

## 3. 员工名单文件（--staff-file）

```
# 员工名单，每行一个（显示名/ID 均可，与消息发送人一致）
张三
李四
王五
```

## 4. 合规规则文件（--rules-file）

```json
[
  {"name": "私域导流", "pattern": "加我微信|加V|扫码加我", "level": "high"},
  {"name": "私下返现", "pattern": "私下返现|返现到账", "level": "high"}
]
```
不传则用内置电商规则（私域导流/私下返现/绝对化话术/内部底价/夸大承诺/辱骂客户）。

## 5. 群值班人映射（--duty，超时扣分归属）

```
--duty "电商运营1群:张三,售后2群:李四"
```
群名必须与消息中的群标题完全一致。

## 6. 自动清理逻辑（无需手动处理）

- 系统消息（撤回/拍了拍/入群/移出/语音通话/接龙等）自动跳过；
- 纯表情、`[图片]`、`[语音]` 等自动跳过；
- 连续刷屏消息去重；
- 缺失 msg_id 时按 `发送人|时间|群|内容` 生成稳定 ID。
