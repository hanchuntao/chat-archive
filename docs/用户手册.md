# chat-archive 用户手册：从微信群记录到报告/知识库

> 适用人群：想把自己微信群的聊天记录导出、整理成报告和知识库的任何人（电商老板、群主、运营、管理者）。
> 不需要懂编程。**Windows / Mac 都支持**，按你的系统选一条路线走即可。

---

## 你要做的三件事（总览）

```
第 1 步  准备环境       安装 Python + chat-archive + 导出工具（一次性，约 10 分钟）
第 2 步  导出明文记录   把你的群记录从微信里取出来（按系统选一条路线，见下）
第 3 步  一键整理       一条命令生成 报告 / 统计 / 跟进事项 / 知识库
```

全程在你自己电脑上运行，**数据不上传任何云端**。

---

## 第 0 步 合规须知（先看）

- **只导出你本人是群主或成员、且你参与其中的群**；导出本群记录做自己团队的整理归档是合法合规的。
- 导出内容**仅供你自己整理使用**。把他人聊天记录公开、转发、商用，需要征得相关人同意。
- 建议在群里告知成员"本群消息会用于内部工作整理"，避免误会。

---

## 第 1 步 准备环境（一次性）

### 1.1 检查 Python（3.9 或更高）

```bash
python3 --version
```

没有或版本过低：去 https://www.python.org/downloads/ 下载安装。

### 1.2 拿到 chat-archive 项目

```bash
# 方式一：git 克隆（推荐）
git clone https://你的仓库地址/chat-archive.git
cd chat-archive

# 方式二：收到压缩包的话，解压后进入目录即可
```

### 1.3 安装导出工具 wechat-cli（获取明文的钥匙）

```bash
# Windows / Mac 通用（需要 Node.js 环境；没有先装：https://nodejs.org）
npm install -g @canghe_ai/wechat-cli
```

> 装完验证：`wechat-cli --version` 能输出版本号即可。
> 若你的电脑已有可用的导出工具（如 WeChatMsg），可跳过本步，直接看第 2 步"路线 C"。

---

## 第 2 步 导出明文记录（三选一，只走一条）

微信电脑版的记录是加密存储的，密钥只在微信运行时的内存里。
**wechat-cli 做的事 = 从内存取密钥 + 解密数据库 + 导出文本**。
各系统难度不同，请按你的情况选路线：

| 路线 | 适合谁 | 难度 |
|---|---|---|
| **A. Windows** | 用 Windows 电脑 | ⭐ 最顺 |
| **B. Mac** | 用 Mac 电脑 | ⭐⭐ Intel 一次过 / Apple Silicon 需特殊步骤 |
| **C. 手机备份** | 不想在电脑上折腾签名 | ⭐⭐ 需要手机配合 |

---

### 路线 A：Windows（最顺，推荐）

**前提**：微信电脑版已登录；微信版本 ≤ 4.1.8.100（新版本暂不兼容，可先装旧版，Windows 无限制）。

**A1. 提取密钥**（一次成功）

右键"命令提示符"或"PowerShell" → **以管理员身份运行**，然后：

```bash
wechat-cli init
```

看到出现密钥表格（Database / Key / Salt）即成功。

**A2. 找到你的群名**

```bash
wechat-cli sessions --limit 500
```

在列表里找到目标群的**完整名字**（例如 `私下家长群-万泉22级五年级7班`）。

**A3. 导出某段时间的记录**

```bash
wechat-cli history "你的群完整名" --start-time "2026-09-01" --format json --limit 20000 > 群记录.json
```

> 后面 `> 群记录.json` 是"保存到文件"的意思，**一定不能漏**，否则只在屏幕上一闪而过。

**A4. 转成项目标准格式**

```bash
cd chat-archive
python3 skill/scripts/convert_wx.py --input ../群记录.json --output 标准记录.json
```

✅ 路线 A 完成，跳到**第 3 步**。

---

### 路线 B：Mac

#### B0. 先试简单流程（Intel Mac 通常一次过）

```bash
wechat-cli init
wechat-cli sessions --limit 500
wechat-cli history "你的群完整名" --start-time "2026-09-01" --format json --limit 20000 > 群记录.json
```

如果 `init` 看到 **Got task port / 密钥表格** → 直接跳到 A4 转格式。
如果看到 **task_for_pid failed: 5** → 你的 Mac 是 Apple Silicon（M 芯片）+ 新系统，走下面特殊步骤。

#### B1. Apple Silicon 特殊步骤（只需做一次）

**为什么特殊**：苹果系统限制读微信内存，需要给微信加一个调试标记（重签），而微信自动更新会把这个标记抹掉。所以顺序是：**先停更新 → 降级到 4.1.8 → 重签 → 提密钥 → 导完再恢复**。

**① 停用微信自动更新**（防止重签被覆盖）：

```bash
PLUG=~/Library/Containers/com.tencent.xinWeChat/Data/Documents/app_data/xplugin/plugins
mv "$PLUG/MacUpdate" "$PLUG/MacUpdate.bak"
mv "$PLUG/MacStoreUpdate" "$PLUG/MacStoreUpdate.bak"
```

（之后想恢复：把 `.bak` 后缀去掉即可。）

**② 装回微信 4.1.8**（需管理员密码，系统弹窗）：

```bash
hdiutil attach ~/Downloads/WeChatMac_4.1.8.dmg -nobrowse -quiet
osascript -e 'do shell script "rm -rf /Applications/WeChat.app && ditto \"/Volumes/微信 WeChat/WeChat.app\" /Applications/WeChat.app" with administrator privileges'
```

> 若没有 4.1.8 安装包：从 CDN 下载 `https://dldir1v6.qq.com/weixin/Universal/Mac/WeChatMac_4.1.8.dmg`。

**③ 打开微信并登录**，等到聊天列表出现内容（数据库已加载）再继续。

**④ 第 1 轮：重签**（在你自己终端，会要求输入开机密码）：

```bash
sudo wechat-cli init --force
```

看到 **"请重新启动微信后再执行 init"** → 完全退出微信（不是最小化）→ 重新打开并登录。

**⑤ 第 2 轮：提密钥**：

```bash
sudo wechat-cli init --force
```

看到 **Got task port** 和密钥表格即成功（末尾显示"提取到 0 个密钥"是工具的文字 bug，忽略，看表格和文件即可）。

**⑥ 导出 + 转格式**：

```bash
wechat-cli history "你的群完整名" --start-time "2026-09-01" --format json --limit 20000 > 群记录.json
cd chat-archive
python3 skill/scripts/convert_wx.py --input ../群记录.json --output 标准记录.json
```

**⑦ 恢复微信**（建议，让微信回到官方最新版）：

```bash
# 恢复更新插件
mv "$PLUG/MacUpdate.bak" "$PLUG/MacUpdate"
mv "$PLUG/MacStoreUpdate.bak" "$PLUG/MacStoreUpdate"
# 装回官方最新版（dmg 挂载后覆盖安装，同②的命令）
```

✅ 路线 B 完成，跳到**第 3 步**。

---

### 路线 C：手机备份（免电脑签名折腾）

适合：不想动电脑微信、或电脑方案不顺利时。

**C1. 手机备份到电脑**

手机微信 → `我` → `设置` → `聊天` → `聊天记录迁移与备份` → `备份` → 备份到电脑（选目标群或全部）。

**C2. 用解析工具导出明文**

用 **WeChatMsg（留痕）** 或其新版 **MemoTrace**：
- Windows：下载官方工具，按界面提示"读取备份 → 导出 JSON/文本"
- 导出后得到文本/JSON 记录

**C3. 转成项目标准格式**

把导出的文件整理成一行一条的文本，形如：

```
[2026-09-01 20:11] 张三: 今天作业是什么
[2026-09-01 20:15] 李四: 见群公告
```

存为 `群记录.txt`，然后：

```bash
cd chat-archive
python3 skill/scripts/convert_wx.py --input ../群记录.txt --output 标准记录.json
```

> 若你的导出工具已输出 JSON 且字段是 `content / senderDisplayName / formattedTime / type / source`，可直接跳过转换，直接喂给第 3 步。

✅ 路线 C 完成，进入第 3 步。

## 第 3 步 一键整理（所有路线汇合）

进入项目目录，一条命令生成全部结果：

```bash
cd chat-archive
python3 skill/scripts/chat_archive.py all \
  --input 标准记录.json --staff all --out 我的输出目录
```

**参数说明**：

| 参数 | 含义 | 示例 |
|---|---|---|
| `--input` | 你的标准记录文件 | `标准记录.json` |
| `--staff` | 员工/成员名单 | `all`=全部发送人；`"张三,李四"`=只统计这几位；`名单.txt`=名单放文件 |
| `--out` | 输出目录（建议用独立文件夹） | `我的输出目录` |

**跑完打开看板**：浏览器打开 `我的输出目录/report.html` —— 一个网页报告，包含全部结果。

**常用变体**：

| 命令 | 效果 |
|---|---|
| `all --mask-all` | 全链路脱敏（连员工昵称/消息表也匿名化，最严格隐私模式） |
| `all --incremental` | 增量模式：按上次运行锚点只处理新消息（重复跑不重复统计） |
| `kb-draft --input ... --staff all --out 目录` | 只生成知识库草稿（`knowledge/*.md` + FAQ），不做统计/考核 |
| `--user 员工` / `--date 日期` | 只出指定员工/指定日期的日报与考核 |
| `--tool-cmd '转换命令 {input} {dir}'` | 传入加密备份时桥接本机 wechat-cli 类工具自动转明文 |

**你会得到这些产物**：

| 产物 | 是什么 |
|---|---|
| `report.html` | 网页看板（浏览器打开即看） |
| `effective_stats.csv` | 成员有效回复统计（谁在积极回复、谁消极） |
| `daily_reports/` | 每人/每日工作日报（去口水总结） |
| `followups.csv` | 讨论要点 + 待跟进事项（防事务架空） |
| `knowledge/` | 知识库（已清洗脱敏，可喂 AI 客服/新人培训） |
| `assessment.csv` | 绩效考核（含证据化评语） |
| `activity.csv` | 群活跃度（话唠榜/活跃时段/熬夜冠军） |
| `messages.csv` | 全部有效消息明细表 |

## 第 4 步 常见问题（遇到再看）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `task_for_pid failed: 5` | Mac 系统限制读内存 | Apple Silicon 走路线 B 特殊步骤；Intel 加 `sudo` 重试 |
| 提取到"0 个密钥" | 工具文字 bug | 忽略，看输出的密钥表格和 `~/.wechat-cli/all_keys.json` |
| `not compatible` / 扫不到密钥 | 微信版本太新 | 需要微信 ≤ 4.1.8.100：Windows 装旧版；Mac 按路线 B 降级 |
| 找不到群名 | 群不在最近列表 | `sessions --limit 500` 或用群名关键词搜索 |
| 转换后条数变少 | 系统消息被归类 | 正常，清洗层会进一步去噪 |
| `command not found: wechat-cli` | 没装好或 PATH 没配 | 重新 `npm install -g`，或加 `--config` 指定路径 |
| 报告是空的 | 消息时间/内容不匹配 | 检查 `--input` 文件是否非空、`--staff` 是否写对 |
